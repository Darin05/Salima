# ponytail-help

Display the ponytail quick reference. One-shot display, no file changes.

## Trigger
`/ponytail-help`, "ponytail help", "ponytail commands"

## Display

```
PONYTAIL — lazy-but-safe coding skill

LEVELS
  /ponytail lite   Build what's asked, name the lazier alternative in one line
  /ponytail        Full mode (default): enforce decision ladder strictly
  /ponytail ultra  YAGNI extremism — challenge requirements before building

COMMANDS
  /ponytail-review   Review current diff for over-engineering
  /ponytail-audit    Scan entire codebase for bloat
  /ponytail-debt     List all ponytail: shortcut comments
  /ponytail-gain     Show benchmark impact scoreboard
  /ponytail-help     Show this reference

CONTROLS
  /ponytail off      Stop ponytail mode
  /ponytail          Resume ponytail mode

DECISION LADDER (applied before writing any code)
  1. Does this need to exist? → skip if no
  2. Stdlib provides it? → use it
  3. Native platform feature? → use it
  4. Installed dependency? → use it
  5. One line? → write one line
  6. Only then: write the minimum working solution

NEVER simplified: validation, security, accessibility, explicitly requested features
```
